---
title: Installation
description: Install Agentdock alongside LangGraph and your chosen LangChain provider.
---

Agentdock does not provide an agent loop, provider wrappers, tools, or checkpoint
drivers. Install the LangChain and LangGraph integrations your application uses.

```bash
npm install @agentdock-ai/agentdock @agentdock-ai/contracts \
  @langchain/core @langchain/langgraph langchain zod
```

Install your model provider integration and checkpoint saver separately. For
the OpenRouter example, also install `@langchain/openrouter`. Node.js 22 or later
is required by Agentdock.

For the optional React chat interface, see [Agentdock UI](/docs/ui) for the
published installer and React runtime package.

## Compatibility

Pass a compiled LangGraph graph to `new Agentdock(graph)`. It must support
`stream()` and `getState()`. Use LangGraph 1.4.17 or newer for native lifecycle
callbacks. No Agentdock state schema or serving metadata is required.

Configure a LangGraph checkpointer when you need saved conversations or
interrupt/resume across requests. Agentdock reads native pending tasks and never
calls `updateState()` to persist event bookkeeping. Your application creates and
closes the saver.
