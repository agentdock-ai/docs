---
title: Interrupt and resume
description: Use LangChain human-in-the-loop middleware and resume through a later request.
---

AgentDock forwards resume values to LangGraph. Approval policy remains inside
the graph, where LangChain's `humanInTheLoopMiddleware` can interrupt a selected
tool before it executes.

```ts
import { humanInTheLoopMiddleware } from "langchain";

const graph = createAgent({
  model,
  tools: [sendEmail],
  checkpointer,
  stateSchema: agentEventStateSchema,
  middleware: [humanInTheLoopMiddleware({ interruptOn: { send_email: true } })],
}).graph;
```

When the stream emits `interrupt_required`, present the pending action to the
authorized user. On approval, make a new request with the same server-derived
`threadId` and the resume payload expected by the graph:

```ts
await runtime.pipe(response, {
  threadId: authorizedThreadId,
  context: trustedContext,
  resume: { decisions: [{ type: "approve" }] },
});
```

The checkpointer and `agentEventStateSchema` preserve event identity and
sequence across requests. AgentDock does not validate the user's authority to
approve a tool: enforce that in the application before sending the resume
command. Configure a durable saver when an interrupt must survive process
restarts or run across multiple server instances.
