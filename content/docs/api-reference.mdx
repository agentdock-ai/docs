## `serveAgent(graph, options?)`

Adapts a compiled LangGraph graph to a small runtime. Input and context types
are inferred from the graph where LangGraph exposes them.

| Option           | Description                                      |
| ---------------- | ------------------------------------------------ |
| `recursionLimit` | Positive LangGraph step limit; defaults to `25`. |

## Runtime methods

| Method                | Description                                             |
| --------------------- | ------------------------------------------------------- |
| `stream(run)`         | Return the transport-free async event iterable.         |
| `pipe(response, run)` | Write SSE events to a Node-compatible response.         |
| `toResponse(run)`     | Return a Web `Response` with a cancelable event stream. |

Starts have `input`, `threadId`, optional `context`, and optional `signal`.
Resumes have `resume`, the same authorized `threadId`, optional `context`, and
optional `signal`. A run must contain exactly one of `input` or `resume`.

## Event state

`agentEventStateSchema` is a composable LangGraph state schema extension for
resumable AgentDock events. Use it with a checkpointer when a stream can pause
for an interrupt and continue in a later request. It is not required for a
simple, uninterrupted stream. AgentDock never creates or closes the saver.

## Ownership boundaries

- The application owns HTTP parsing, authentication, authorization, and
  thread-ID derivation.
- The application constructs the graph, configures provider credentials and
  tools, and creates/closes checkpoint resources.
- The graph owns tool policies, including approval and resume payloads.
- AgentDock owns stream adaptation, event mapping, transport cancellation, and
  the checkpoint-backed event continuity fields.

The package does not expose an agent class, provider abstraction, tool
registry, session API, or model/tool loop.
