AgentDock is a small serving adapter for compiled LangGraph graphs. It forwards
application input, trusted context, and thread IDs into LangGraph and maps graph
stream chunks to the AgentDock event contract.

LangChain and LangGraph build and run the agent. Your application owns model
providers, tools, identity, authorization, checkpoint storage, and HTTP request
handling.

The value bar is intentionally narrow: with the same application setup,
`serveAgent` should reduce the endpoint-specific handler to five lines or fewer
while handling event mapping, SSE framing, backpressure, disconnect cancellation,
terminal errors, and response cleanup.

## Start here

1. [Install the packages](./installation).
2. [Build and serve an agent](./quickstart) with `createAgent`.
3. Learn how [interrupt and resume](./approvals) works across requests.
4. Review [events](./events) or the [API reference](./api-reference).

The [HTTP ReAct example](./example) combines a weather tool, an approval-gated
email tool, request validation, trusted context, and a server-derived thread ID.
