---
title: Events
description: Consume AgentDock events and reduce them into UI state.
---

`runtime.stream(run)` returns an async iterable of JSON-safe `AgentEvent`
objects. `runtime.pipe(response, run)` encodes the same events as
Server-Sent Events; `runtime.toResponse(run)` exposes them in a Web `Response`.
All event types and reducer utilities are exported from
`@agentdock-ai/contracts` and re-exported from `@agentdock-ai/agentdock`.

```ts
import {
  createAgentReducerState,
  reduceAgentEvent,
} from "@agentdock-ai/agentdock";

let state = createAgentReducerState();
for await (const event of runtime.stream(run)) {
  state = reduceAgentEvent(state, event);
  render(state);
}
```

The contract covers run lifecycle, assistant text, tool calls and results,
interrupts, and errors. Chunks that cannot be mapped to those contract types
are exposed as custom content/events where supported. The application or UI
owns rendering and any persistence of reduced state.

For interrupted runs that continue in a later request, add
`agentEventStateSchema` to the graph schema and use a LangGraph checkpointer.
The runtime stores only the minimal checkpointed event identity, sequence, and
pending interrupt ID needed to continue the contract.
